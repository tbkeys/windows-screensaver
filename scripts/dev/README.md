Standalone pages and headless-Chromium scripts for eyeballing one module at a time while developing: run `npx vite`, open `http://localhost:5173/scripts/dev/<name>.html`, or run `node scripts/dev/shoot-<name>.mjs [port]` / `check-<name>.mjs` to screenshot or measure it.
Nothing here is part of the build or the published site; screenshots land in `scripts/out/` (git-ignored).
