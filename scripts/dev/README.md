Standalone pages and headless-Chromium scripts for eyeballing one module at a time while developing: run `npx vite --port 5173`, open `http://localhost:5173/scripts/dev/<name>.html`, or run `node scripts/dev/shoot-<name>.mjs 5173` / `node scripts/dev/check-textures.mjs 5173` to screenshot or measure it (pass the port your dev server uses; `verify-app.mjs` serves a built `dist/` itself). All scripts launch Chromium through `scripts/lib/chromium.mjs` (`CHROMIUM_PATH` overrides the browser).
Nothing here is part of the build or the published site; screenshots land in `scripts/out/` (git-ignored).
